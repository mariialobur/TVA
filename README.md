> [!IMPORTANT]
> Ce projet est un **support pédagogique indépendant consacré à la TVA suisse**. Il ne constitue ni une prise de position officielle de l’AFC/ESTV, ni un conseil fiscal individualisé, ni une certification professionnelle reconnue. Les règles, taux, seuils, délais, pratiques administratives et jurisprudences doivent être vérifiés dans leur version en vigueur avant toute utilisation professionnelle.

La **Formation de spécialiste TVA suisse** a été conçue comme un parcours de travail, pas comme une simple collection de fiches théoriques. Chaque module combine explications, raisonnements TVA, cas pratiques, questions de contrôle, autotests et outils de révision afin de développer progressivement les réflexes nécessaires à l’analyse d’un dossier réel.

Le parcours couvre les fondamentaux de la TVA suisse, la qualification des opérations, les méthodes de décompte, la comptabilisation, la déduction de l’impôt préalable, la territorialité, les groupes TVA, l’immobilier, les secteurs sensibles, les plateformes numériques, le contrôle AFC, la jurisprudence et la communication fiscale. Il se termine par un examen blanc de synthèse.

## ✨ Ce que contient le parcours

### `1` Un apprentissage construit autour de cas pratiques

L’objectif n’est pas seulement de mémoriser des articles de loi. Les modules demandent d’identifier la bonne question TVA, de qualifier l’opération, de déterminer le traitement applicable et de justifier la réponse.

- cas pratiques intégrés aux modules ;
- questions progressives avec explications ;
- autotests et contrôles de compréhension ;
- calculs et raisonnements TVA ;
- références légales et points d’attention ;
- mémo-fiches et outils de révision selon les modules.

### `2` Quatorze modules autonomes mais progressifs

Chaque module peut être ouvert directement depuis le dashboard. Le parcours reste néanmoins conçu pour avancer de **M01 à M14**, des bases jusqu’aux situations à risque et à la synthèse finale.

### `3` Une progression conservée dans le navigateur

Le dashboard enregistre localement l’état d’avancement du parcours. Aucun compte n’est nécessaire et aucune donnée personnelle n’est envoyée vers un serveur pour suivre la progression.

### `4` Une attention particulière aux zones TVA à risque

Le projet contient une **Legal QA Checklist** séparée pour les points susceptibles d’évoluer ou d’exiger une vérification renforcée : taux, seuils, méthodes de décompte, DIP, territorialité, immobilier, plateformes, contrôle AFC, jurisprudence et autres sujets sensibles.

### `5` Un examen blanc de synthèse

Le dernier module est consacré à la consolidation des acquis. Il permet de tester la capacité à mobiliser plusieurs thèmes TVA dans une même analyse plutôt que de répondre uniquement à des questions isolées.

## ▶️ Utilisation

Aucune installation n’est nécessaire pour suivre le cours : ouvrez simplement le **[dashboard GitHub Pages](https://mariialobur.github.io/TVA/)** dans un navigateur moderne.

Pour travailler avec une copie locale du projet :

```bash
git clone https://github.com/mariialobur/TVA.git
cd TVA
```

Ouvrez ensuite `index.html` dans votre navigateur, ou servez le dossier avec le serveur HTTP local de votre choix.

> 💡 La progression du dashboard est stockée dans le `localStorage` du navigateur. Changer de navigateur, de profil ou effacer les données du site peut donc réinitialiser l’état d’avancement.

## ⚖️ Validation fiscale et juridique

La TVA suisse évolue par la loi, les ordonnances, la pratique administrative et la jurisprudence. Une réponse correcte à une date donnée peut devenir incomplète ou nécessiter une nuance ultérieure.

Avant d’utiliser un élément du cours dans un dossier professionnel, il convient notamment de contrôler :

- la **LTVA** et l’**OTVA** dans leur version en vigueur ;
- les publications, infos TVA, pratiques et communications de l’**AFC/ESTV** ;
- les taux, seuils, délais et méthodes applicables à la période concernée ;
- la jurisprudence pertinente lorsqu’elle influence le traitement ;
- les faits précis du dossier client, qui peuvent modifier la qualification TVA.

La page [`legal-qa-checklist.html`](https://mariialobur.github.io/TVA/legal-qa-checklist.html) sert de garde-fou pour cette vérification.

## 🛠 Technique

Le projet reste volontairement léger :

- **HTML5** pour la structure des modules ;
- **CSS** intégré pour l’interface ;
- **JavaScript vanilla** pour les interactions, quiz et progression ;
- **localStorage** pour l’état d’avancement local ;
- **GitHub Pages** pour l’hébergement ;
- aucun backend ni base de données requis pour suivre le cours.

Cette architecture permet au parcours de rester facilement consultable et déployable sans infrastructure applicative complexe.

## 🔎 État du projet

Le socle technique et les 14 modules sont publiés. Le contenu fait l’objet d’une **revue progressive module par module** afin d’améliorer simultanément :

- l’exactitude TVA et la traçabilité des références ;
- la qualité pédagogique des explications ;
- la cohérence entre les modules ;
- l’ergonomie des exercices et autotests ;
- la distinction entre règle générale, exception, pratique AFC et jurisprudence.

Les corrections sont versionnées dans Git afin de conserver l’historique des évolutions.
